# SLA Auto-Escalation Feature

Jira Item: HDL-12

Purpose:
Automatically escalate support tickets that exceed their SLA.

Expected Behavior:
- Monitor unresolved tickets.
- Detect SLA breaches.
- Mark tickets as escalated.
- Notify the responsible manager.

Evidence:
- Unit tests pass.
- Escalation logic works correctly.
- Notifications are triggered.
